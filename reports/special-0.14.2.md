## `special::Beta::inv_inc_beta`

- **Dataset:** `reference/data/betaincinv.jsonl`: Inverse of the regularized incomplete beta function: the x with I_x(a, b) = p (the beta distribution's quantile function)
- **References:** mpmath 1.4.1, SciPy 1.18.1
- **Grid:** a, b in {0.1, 0.5, 1, 2, 5, 10, 100, 1000, 10000} x p in {0, 5e-324, 1e-300, 1e-100, 1e-20, 1e-10, 1e-5, 1e-3, 0.01, 0.1, 0.25, 0.5, 0.75, 0.9, 0.99, 0.999, and the doubles nearest 1 - 1e-5, 1 - 1e-10, 1 - 1e-15, 1}; the quantile is 0 at p = 0 and 1 at p = 1 (the ends of the support, so not poles); for small a the lower-tail quantiles are below the smallest double, and for small b the upper-tail quantiles round to 1
- **Tolerance:** 2e-13 relative. a, b and p are exact doubles and 1 - p is exact for p >= 1/2, but in the lower tail the quantile is x = exp(L) with L = log(p a B(a, b)) / a approximately; rounding L (or 1/a, which multiplies it) to a double changes x by |L| times 2^-53. The largest |L| at a nonzero, normal quantile below 1 on this grid is 700.0 (a = 1, b = 1e4, p = 1e-300, x = 1e-304), so up to 7.8e-14 is unavoidable; near x = 1 the same holds for 1 - x, which moves x by less. 2e-13 allows 2.6x that and matches t_ppf and gamma_ppf. SciPy's worst error at the points it gets within tolerance is 2.0e-13 (a = 1000, b = 1e4, p = 0.75); it fails 105 points: NaN for 29 points with p <= 1e-300, about 2.2e-308 (just below the smallest normal double) where the quantile is smaller (41 points), errors from 1.2e-12 to 911x at 33 points with p <= 1e-300 (e.g. 0.375 instead of 0.477 at a = 1000, b = 0.5, p = 5e-324), and 2.8e-13 and 2.1e-13 at a = 1000, b = 1e4, p = 0.999 and 1 - 1e-5
