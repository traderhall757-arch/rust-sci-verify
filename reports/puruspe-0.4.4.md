## `puruspe::erfcx`

- **Dataset:** `reference/data/erfcx.jsonl`: Scaled complementary error function erfcx(x) = exp(x^2) erfc(x)
- **References:** mpmath 1.4.1, SciPy 1.18.1
- **Grid:** x = -30..30 step 0.25, plus +-10^k for k = -300..300 step 10; negative x below about -26.6 overflows
- **Tolerance:** 1e-13 relative. For negative x the value is about 2*exp(x^2), and merely rounding x^2 to a double costs up to x^2 * 2^-53 relative error (about 8e-14 at x = -26.6, the overflow edge); 1e-13 accepts that unavoidable loss and nothing more
- **Worst case:** x = 1.8e1 gives 3.1295717815905205e-2 (mpmath 3.129571781590521e-2), rel. error 2.2e-16

## `puruspe::gammp`

- **Dataset:** `reference/data/gammainc.jsonl`: Regularized lower incomplete gamma function P(a, x) = gamma(a, x) / Gamma(a)
- **References:** mpmath 1.4.1, SciPy 1.18.1
- **Grid:** a in {0.1, 0.5, 1, 2, 5, 10, 20, 50, 100, 200, 500, 1000} x x in {0, 0.001, 0.01, 0.1, 0.5, 1, 2, 5, 10, 20, 50, 100, 200, 500, 1000, 2000}
- **Tolerance:** 1e-12 relative. P is the prefix x^a e^-x / Gamma(a + 1) times a well-conditioned series or continued fraction. On this grid the logarithms of the prefix's factors reach 1.6e4 in magnitude while their sum stays above -745; forming them separately in double precision loses up to 1.6e4 * 2^-53 (about 2e-12), and combining them before rounding (Temme; Boost) loses far less. 1e-12 demands the careful approach and is 3x the worst SciPy error on this grid (3.5e-13 at a = 1000, x = 500)
- **Worst case:** a = 1e3, x = 5e2 gives NaN (mpmath 3.2982727970671e-86), rel. error inf
